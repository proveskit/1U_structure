# 1U_structure
This repo contains files for the baseline 1U CubeSat Kit structure along with some other helpful tools! 

## Feet

The `feet/` folder holds the current foot designs used on every PROVES Kit. They replace the longer feet with two vertical fasteners, which are retired.

| File | Size (mm) | Top face |
|---|---|---|
| `feet/foot_solid.step` | 13.9 × 23.7 × 13.9 | Solid |
| `feet/foot_gusset.step` | 14.0 × 23.8 × 14.0 | Bored through, with a gusset |

`1U Assembly.step` still shows the retired feet.
